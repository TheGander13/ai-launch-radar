# AI Launch Radar — план сайту

## Мета
Допомогти швидко знаходити **нові AI-продукти раніше, ніж про них напишуть медіа**: моніторинг ринку, пошук конкурентів, ідеї для продуктів.

Бізнес-мета в перспективі: органічний трафік через programmatic SEO (тисячі сторінок ніш, сайтів і порівнянь) + ліди (email-дайджест, платні алерти по нішах).

## Аудиторія
1. **Фаундери та PM AI-стартапів** — моніторинг конкурентів у своїй ніші.
2. **Інвестори, скаути, акселератори** — рання видача нових проєктів.
3. **SEO-фахівці та маркетологи** — нові сайти для партнерств, лінкбілдингу, аутрічу.
4. **Вайб-кодери та інді-хакери** — що зараз запускають на Lovable / v0 / Bolt / Base44 і в яких нішах.
5. **Tech-журналісти та блогери** — джерело новинок для оглядів.

## Сторінки (MVP — реалізовано)
| Сторінка | URL | Що робить |
|---|---|---|
| Radar | `/` | Стрічка нових AI-стартапів (`ai_startups=1`), пошук, фільтри: ніша, стек, DR, сортування; статистика індексу |
| Built with AI | `/?tab=built` | Сайти на AI-конструкторах (`ai_source`), чипи з кількістю сайтів по кожному |
| Compare | `/?tab=compare` | Порівняння до 3 сайтів поруч + «Find similar» (конкуренти в тій самій ніші) |

Стан фільтрів зберігається в URL — будь-якою вибіркою можна поділитися посиланням.

## Структура (наступний етап — під SEO)
| URL | Сторінка |
|---|---|
| `/` | Radar (головна) |
| `/niche/{slug}` | 15 сторінок ніш: image-generation, ai-agents, voice-tts… |
| `/built-with/{builder}` | lovable, v0, bolt, base44 |
| `/site/{domain}` | Картка сайту: опис, ніша, стек, DR, схожі сайти |
| `/compare/{a}-vs-{b}` | Сторінки порівнянь |
| `/weekly/{yyyy-ww}` | Щотижневий дайджест новинок (архів) |
| `/about` | Про проєкт і джерело даних |

## SEO
- **Цільові запити:** «new AI startups», «AI tools directory», «{niche} AI tools», «sites built with Lovable», «{tool} alternatives», «{a} vs {b}».
- **Мета-теги за шаблонами**, унікальні для кожної сторінки. Приклад для `/niche/image-generation`: title — «New AI Image Generation Tools — {Month} {Year} | AI Launch Radar», description — «{N} new image generation startups, sorted by launch date and Domain Rating. Updated daily.»
- **Розмітка schema.org:** `WebApplication` (вже є), `ItemList` для списків, `BreadcrumbList`, `SoftwareApplication` на `/site/`.
- **Технічне:** зараз контент рендериться в браузері — для індексації потрібен SSG/SSR (Next.js + ISR, оновлення раз на добу), `sitemap.xml`, `canonical`, `robots.txt`.
- **Перелінковка:** ніша ↔ сайт ↔ схожі сайти ↔ порівняння ↔ дайджест.
- **Якість:** не індексувати «тонкі» сторінки (без опису, шумні записи — агенції, магазини), `noindex` для комбінацій фільтрів.

## Метрики успіху
- Органічні покази та кліки (Google Search Console), кількість проіндексованих сторінок.
- CTR з карток на сайти стартапів, використання Compare і «Find similar».
- Підписки на дайджест (наступний етап).
